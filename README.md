# Find The Singer / 寻找歌姬

Please find the Grenyes. A small Godot 4 platformer — play it on [itch.io](https://kuthorx.itch.io/find-the-singer).

## Languages

The game ships in **English** and **简体中文**.

- On first launch the language follows the system/browser locale (Chinese → 中文, anything else → English).
- Use the **中文 / EN** button under Start on the title screen to switch; the choice is saved to `user://settings.cfg`.
- All UI text lives in `i18n/translations.csv` (`keys,zh,en`). Add a key there and use it as a Control's text (auto-translated) or via `tr()` in scripts.
- UI text uses Caveat (SIL OFL, `fonts/OFL-Caveat.txt`) with a renamed GB2312 subset of LXGW WenKai as the CJK fallback (SIL OFL, `fonts/OFL-FTSHand-CJK.txt`), both wired up in the global theme `ui/notebook_theme.tres`. If you add rare Chinese characters to the CSV, re-run `python3 tools/art/build_fonts.py <Caveat[wght].ttf> <LXGWWenKai-Regular.ttf>`.

## Art

All art is generated by code: `python3 tools/art/gen_art.py` repaints every PNG in `images/` (except `ElementSource.png`, which is the app icon). The direction is described in `docs/art-direction.md`. The clef and note shapes come from the Bravura music font (SIL OFL, `tools/art/fonts/`).

For headless screenshots of the web build, open `index.html?shot=gameplay|finish|gameover` to jump straight to that screen.
