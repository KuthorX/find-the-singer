# Find The Singer / 寻找歌姬

Please find the Grenyes. A small Godot 4 platformer — play it on [itch.io](https://kuthorx.itch.io/find-the-singer).

## Languages

The game ships in **English** and **简体中文**.

- On first launch the language follows the system/browser locale (Chinese → 中文, anything else → English).
- Use the **中文 / EN** button under Start on the title screen to switch; the choice is saved to `user://settings.cfg`.
- All UI text lives in `i18n/translations.csv` (`keys,zh,en`). Add a key there and use it as a Control's text (auto-translated) or via `tr()` in scripts.
- UI text uses Caveat (SIL OFL, `fonts/OFL-Caveat.txt`) with a renamed GB2312 subset of LXGW WenKai as the CJK fallback (SIL OFL, `fonts/OFL-FTSHand-CJK.txt`), both wired up in the global theme `ui/notebook_theme.tres`. If you add rare Chinese characters to the CSV, re-run `python3 tools/art/build_fonts.py <Caveat[wght].ttf> <LXGWWenKai-Regular.ttf>`.

## Art

All art is generated by code: `python3 tools/art/gen_art.py` repaints every PNG in `images/` except the app icon, which `python3 tools/art/gen_icon.py` paints from the same pen (`icon.png`, `icon.ico` for Windows, `icon_web_*.png` for the web favicon and apple-touch icon; the script also inlines the 32 px favicon into the Web preset's `html/head_include`). The direction is described in `docs/art-direction.md`. The clef and note shapes come from the Bravura music font (SIL OFL, `tools/art/fonts/`).

## Audio

Music & SFX composed programmatically by AI (Claude) and rendered with Vital / Serum 2 / MS Basic soundfont. The score is written in Python (`tools/audio/score.py`) and orchestrated with Serum 2 factory presets, Vital (GPL-3.0; "In The Mix" and Databroth factory preset packs) and the MIT-licensed MS Basic SoundFont, all rendered offline; the SFX layer numpy pen-and-paper foley with tones rendered from the same instruments. The concept is "the unfinished song": the gameplay melody fills in as you collect letters. The cue sheet is in `docs/audio-direction.md`, and sources and licenses are in `audio/LICENSES.md`. Music and effects volume and mute are on the title screen, and **M** toggles mute anywhere.

For headless screenshots of the web build, open `index.html?shot=gameplay|finish|gameover` to jump straight to that screen.
